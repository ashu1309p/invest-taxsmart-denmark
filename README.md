# v2-improvements — revised version implementing IMPROVEMENTS.md

The next iteration of the site, built on top of `../fintech-redesign/` and implementing
`../fintech-redesign/IMPROVEMENTS.md`. Same guardrails as the rest of the repo: stateless/static,
one `TAX_YEAR_CONFIG`, year-tagged numbers, no advice, bilingual via `I18N`, no heavy frameworks.
Tax math, `simulateRouted`, and the self-tests are untouched (Plan 9/9, Play 12/12).

`_baseline/` holds the pristine pre-change copies. `PROGRESS.md` is the resume file and task tracker.

## Going live: wire the real positivliste data
The shipped `data/positivliste.json` is a **sample**, not SKAT's list (the UI says so on every result).
To make the checker authoritative:
1. Open SKAT's page: https://skat.dk/erhverv/ekapital/vaerdipapirer and find the current
   "Liste over aktiebaserede investeringsselskaber" `.xlsx` direct link.
2. In the GitHub repo, set a repository **variable** `POSITIVLISTE_URL` to that link
   (Settings → Secrets and variables → Actions → Variables), or edit `DEFAULT_URL` in
   `scripts/build_positivliste.py`.
3. Run the **Refresh positivliste snapshot** workflow once (Actions tab → Run workflow). It rebuilds
   `data/positivliste.json` from the real file; thereafter it refreshes weekly.
4. Confirm the checker now shows a real `listDate` and the sample warning is gone.

If the SKAT sheet layout changes, the script's column detection (`find_columns`) may need a tweak.
